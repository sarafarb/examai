# ExamAI Monorepo

This is the main repository for the ExamAI platform.

## Project Structure
- `src/backend/` - .NET Web APIs, Background Workers, and Shared Class Libraries.
- `src/frontend/` - Frontend client applications (`examai-web`).
- `infra/` - DevOps configurations containing Docker, Kubernetes configurations, and helper scripts.
- `docs/` - System architecture and documentation.
- `.github/workflows/` - CI/CD pipeline definitions.
